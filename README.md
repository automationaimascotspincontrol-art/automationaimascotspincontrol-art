## 📦 Featured Project — `VectorQuant`

> A Python library for **Vector Quantization & clustering**, built for ML pipelines and data compression.

<p align="left">
  <img src="https://img.shields.io/pypi/v/vectorquant?label=version&color=FF8C00&logo=pypi&logoColor=white"/>
  <img src="https://img.shields.io/pypi/dm/vectorquant?label=downloads&color=FFA500"/>
  <img src="https://img.shields.io/pypi/pyversions/vectorquant?color=FF6B00"/>
  <img src="https://img.shields.io/pypi/l/vectorquant?color=orange"/>
</p>

```bash
pip install vectorquant
```

```python
from vectorquant import VectorQuant

vq = VectorQuant(k=256)      # 256-cluster codebook
vq.fit(data)                 # learn the quantizer

compressed = vq.encode(data) # → compact codes
decoded    = vq.decode(compressed)  # ← reconstruct
```

🔗 **PyPI:** https://pypi.org/project/vectorquant/
